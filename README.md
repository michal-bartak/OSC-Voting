# OSC Voting

A companion desktop app for voting in the [One Synth Challenge](https://onesynthchallenge.org) — playlist-style playback, simplified voting, and one-click timed comments on SoundCloud.

![Screenshot](docs/screenshot.gif)

📖 **[Full documentation](https://michal-bartak.github.io/OSC-Voting/)**

## Quick start

Download the latest release for your platform from the [Releases page](../../releases).  
See the [Installation guide](https://michal-bartak.github.io/OSC-Voting/installation) for platform-specific steps.

**Developers:**
```bash
git clone https://github.com/michal-bartak/OSC-Voting.git
cd OSC-Voting
make dev
```
See [Building from Source](https://michal-bartak.github.io/OSC-Voting/building) for requirements.
